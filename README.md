# Thư mục ảnh - Sàn gỗ Minh Đức

Thả các file ảnh vào đây, giữ đúng tên để web tự nhận:

| Tên file | Dùng ở đâu | Kích thước gợi ý |
|---|---|---|
| `logo.svg` | Icon logo (bản vẽ lại tạm - đang dùng). Có file logo gốc thì thay `logo.svg` hoặc đổi sang `logo.png` trong `index.html` | SVG / PNG nền trong suốt |
| `anh-chu.jpg` | Ảnh người sáng lập ở mục "Giới thiệu" | 800 x 800px |
| `hero.jpg` | (tùy chọn) ảnh phòng khách lát sàn cho khối hero | 1600 x 1000px |
| `sp-1.jpg` ... `sp-4.jpg` | Ảnh 4 mẫu sàn nổi bật | 800 x 600px |
| `du-an-1.jpg` ... `du-an-6.jpg` | Ảnh 6 công trình | 1000 x 700px |

Hiện web đang dùng nền màu gradient thay ảnh. Khi có ảnh thật, báo lại để mình gắn vào từng vị trí.
